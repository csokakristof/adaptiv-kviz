# Foci Kvíz

React alapú webes kvízalkalmazás adaptív kérdésválasztással, XP-rendszerrel és statisztikai megjelenítéssel.

## Futtatás

A projekt futtatásához szükséges a Node.js és az npm telepítése.

A szükséges csomagok telepítése:

```bash
npm install  
```

Az alkalmazás indítása:

```bash
npm install
```
